# 🟢 Hibernate CRUD Program (Maven + MySQL)

This is a simple **Hibernate CRUD application** built using **Maven, Java, and MySQL**.  
It demonstrates basic ORM operations like Create, Read, Update, and Delete.

---

## 🚀 Technologies Used

- Java (JDK 8+)
- Hibernate ORM
- Maven
- MySQL Database
- JDBC Driver (MySQL Connector)
- IDE: Eclipse
